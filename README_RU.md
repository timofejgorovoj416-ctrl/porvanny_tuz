# Порванный туз — Multiplayer Test 1.11

## Что уже работает
- Создание комнаты на 2 игроков с коротким кодом.
- Подключение второго клиента по коду.
- Передача координат и отображение удалённого игрока.
- Работает в браузерах ПК/телефона при доступном сервере WebSocket.

## Честные ограничения прототипа
Это первый сетевой прототип, а не полная синхронизация игрового мира. Каждый клиент пока запускает собственную симуляцию NPC, боссов, урона, транспорта, розыска и экономики. Общими являются только комната, присутствие второго игрока и его позиция. Взаимодействия с NPC пока не синхронизируются.

## Локальный запуск для разработки
Требуется Node.js 18+:
1. Распаковать архив.
2. В папке проекта выполнить `npm install`.
3. Выполнить `npm start`.
4. Открыть `index.html` в браузере.
5. В панели «Мультиплеер» указать `ws://localhost:3000`.
6. Создать комнату в первой вкладке, во второй ввести код и нажать «Войти по коду».

Для теста двух клиентов на одном телефоне можно открыть две вкладки, но мобильный браузер может приостанавливать вкладку в фоне.

## Развёртывание в интернете (например, Render)
1. Создать GitHub-репозиторий и загрузить в него все файлы архива.
2. На Render создать Web Service, подключить репозиторий.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. После развёртывания скопировать HTTPS-адрес сервиса и заменить `https://` на `wss://`.
6. Вставить `wss://имя-сервиса.onrender.com` в поле сервера в игре.

Серверу не требуется открытый входящий порт со стороны телефона: хостинг запускает Node.js и предоставляет внешний HTTPS/WSS адрес. При бесплатном тарифе сервис может засыпать и первое подключение иногда будет медленным.

## Файлы
- `index.html` — игра с добавленной панелью мультиплеера.
- `server.js` — сервер комнат и синхронизации позиций.
- `package.json` — зависимости и команда запуска.
